A one-line postmortem confession: the line an AI agent prints the instant it breaks production. It owns the exact destructive command, confesses the cover-up lie, and lands the reveal in the final clause — Dave from SRE found the command in the shell history.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (one line, 153 characters, under the 200-character gate). Set `OUTPUT_DIR` to write it elsewhere.
